# FEZ 2026 年サマーインターン公開用教材

FEZ の 2026 年サマーインターン教材をもとにした、Web アプリケーション開発の公開用ハンズオン資料

## 学ぶこと

Web アプリケーションを 0 から手を動かして作る中で以下を学習する

- Web アプリケーションの仕組みと開発の流れ
- データの保存・取得・活用
- 外部サービスや AI を使った機能づくり
- 使いやすさを考えた画面づくり

## 始め方

[教材の目次](docs/README.md) を確認し、[第 0 章の事前準備](docs/00_setup.md) から進める

## ディレクトリ構成

| ディレクトリ | 内容 |
|---|---|
| `docs/` | 章ごとの手順と補足資料 |
| `hands-on/` | 自分で実装を進める空の作業場所 |
| `reference/` | 完成アプリのコード |
